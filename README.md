# Pysar
Pysar — a cross-platform report engine for .NET. Describe a paginated document once in .rxaml markup or a fluent C# builder, supply your data, and get a vector PDF, bitmap pages, or an in-app view — rendered by plain .NET on SkiaSharp across Windows, macOS, Linux, Android, iOS and the browser (MAUI, Avalonia, WPF, Blazor). MIT licensed.
